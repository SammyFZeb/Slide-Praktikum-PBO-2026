# Constructor

<div class='grid grid-cols-2 gap-x-3'>

<div>

<p>
  Constructor adalah bagian khusus dari suatu class yang dipanggil ketika suatu objek sedang dibuat.Fungsinya adalah untuk menentukan atribut suatu objek baik secara default atau dari nilai yang ditentukan oleh user.
</p>

- Constructor bisa dibilang sebagai *special method* atau fungsi khusus dalam OOP.
- Nama dari constructor harus **sama dengan nama classnya** dan **tidak memiliki return type**.

Ada 2 tipe constructor, yaitu **default constructor** dan **regular constructor**.
</div>

<div>

```java {all}
class Mobil {
    public Mobil() {
        //isi kode disini
    }
}
```
