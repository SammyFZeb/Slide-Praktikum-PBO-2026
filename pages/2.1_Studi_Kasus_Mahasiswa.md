# Studi Kasus

<p class="text-sm opacity-70 mt-1">
Dosen membutuhkan aplikasi sederhana untuk menghitung nilai akhir mahasiswa
berdasarkan akumulasi beberapa komponen nilai.
</p>

<div class="grid grid-cols-[1fr_0.85fr] gap-6 items-start mt-4 text-sm">

<div>

### 1. Class `Mahasiswa`

Buat class <code>Mahasiswa</code> dengan atribut: <code>nama</code>, <code>nilaiKuis</code>, <code>nilaiUts</code>, <code>nilaiUas</code>

**Ketentuan:**

<ul class="text-[11px] leading-4 text-white-500 m-0 mt-1 space-y-1 list-disc list-inside">
  <li>Semua atribut bersifat <code>private</code>.</li>
  <li>Buat constructor berparameter.</li>
  <li>Buat getter dan setter untuk seluruh atribut.</li>
  <li>Buat method <code>hitungNilaiAkhir()</code>dengan bobot: Kuis 20%, UTS 40%, UAS 40%.</li>
</ul>
 
<p></p>

### 2. Class `Main`
**Ketentuan:**

<ul class="text-[12px] leading-4 text-white-500 m-0 mt-1 space-y-1 list-disc list-inside">
  <li>Input nama & tiga komponen nilai menggunakan <code>Scanner</code></li>
  <li>Tampilkan ringkasan & nilai akhir.</li>
</ul>
