# Method Overloading (Lanjutan)

<div class="text-left text-base leading-normal space-y-4">

<ul class="list-disc list-inside space-y-2">
  <li>Salah satu fungsionalitas dari Java dimana satu class bisa memiliki beberapa method (fungsi) dengan nama yang sama tetapi parameter yang berbeda-beda.</li>
  <li>Compiler akan secara otomatis menentukan fungsi mana yang paling cocok dengan inputan yang diberikan.</li>
</ul>

<h3 class="text-base font-bold text-blue-400 mt-4">Syarat:</h3>

<ul class="list-disc list-inside space-y-2">
  <li>List parameter <b>harus berbeda</b> (jumlah, tipe data, urutan).</li>
  <li><b>TIDAK BOLEH</b> overload hanya berdasarkan perbedaan return type (untuk overloading method).</li>
</ul>

</div>
