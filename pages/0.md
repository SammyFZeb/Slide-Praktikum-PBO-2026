Berikut adalah 2 pilihan format yang sudah dirapikan agar proporsional di layar Slidev:

---

### Opsi 1: Layout 2 Kolom (Sangat Seimbang & Rapi) 🔥
Daripada ditumpuk ke bawah (yang bikin teks terdorong ke pinggir), kita bagi menjadi 2 sisi: **Ketentuan Tugas di kiri** dan **Contoh Output di kanan**.

```markdown
---
layout: center
---

# Assignment: CLI Menu Interaktif

<div class="grid grid-cols-12 gap-8 mt-6 items-center">

  <!-- Kiri: Spesifikasi Tugas (7 Kolom) -->
  <div class="col-span-7 text-sm space-y-4">
    <p class="text-gray-500 m-0">
      Buatlah program CLI berbasis menu interaktif dengan ketentuan berikut:
    </p>

    <div class="space-y-3">
      <!-- Poin 1 -->
      <div class="border-l-2 border-blue-500 pl-3">
        <span class="font-bold">1. Class Entitas</span>
        <p class="text-xs text-gray-500 m-0 mt-0.5">
          Misal: <code>Produk</code> / <code>Kendaraan</code> / <code>Buku</code>.<br>
          Wajib memiliki minimal <b>2 instance attributes</b> dan <b>1 static attribute</b> <i>(counter objek)</i>.
        </p>
      </div>

      <!-- Poin 2 -->
      <div class="border-l-2 border-emerald-500 pl-3">
        <span class="font-bold">2. Skema Menu Perulangan</span>
        <ul class="text-xs text-gray-500 m-0 mt-1 space-y-0.5 list-disc list-inside">
          <li><b>Input Data Baru:</b> Menerima input & buat objek baru.</li>
          <li><b>Cek Total Data:</b> Panggil static method total objek.</li>
          <li><b>Keluar:</b> Menghentikan program.</li>
        </ul>
      </div>
    </div>
  </div>

  <!-- Kanan: Contoh Output (5 Kolom) -->
  <div class="col-span-5">
    <span class="text-xs font-mono uppercase text-gray-400 block mb-2">Contoh Output:</span>
```text
=== SISTEM MANAJEMEN BUKU ===
1. Input Data Baru
2. Cek Total Data
3. Keluar
Pilih menu (1-3): 
```
  </div>

</div>
```

### Opsi 2: Markdown Murni yang Rapi (Tanpa Tag HTML Rumit)
Jika kamu lebih nyaman menggunakan format Markdown murni atas-bawah tanpa banyak tag `<div>`:

```markdown
---
layout: center
---

<div class="max-w-3xl mx-auto text-sm leading-relaxed">

# 📋 Assignment: CLI Menu Interaktif

Buat program CLI berbasis menu interaktif dengan ketentuan:

1. **Class Entitas** (misal: `Produk` / `Kendaraan` / `Buku`):
   - Minimal **2 instance attributes**.
   - Minimal **1 static attribute** sebagai penghitung objek.

2. **Skema Perulangan Menu**:
   - `1.` **Input Data Baru** &rarr; Menerima input & buat objek baru.
   - `2.` **Cek Total Data** &rarr; Memanggil *static method* total instance.
   - `3.` **Keluar** &rarr; Menghentikan loop program.

<div class="mt-4">

```text
=== SISTEM MANAJEMEN BUKU ===
1. Input Data Baru
2. Cek Total Data
3. Keluar
Pilih menu (1-3):
```

</div>

</div>
```

### Apa saja yang diperbaiki:
1. **Menghilangkan tag `<br>` kosong** di bawah judul yang membuat spasi berlebih.
2. **Menambahkan format kode (`` `Buku` ``, `` `1.` ``)** agar lebih mudah dibedakan antara narasi soal dan istilah pemrograman.
3. **Menggunakan `layout: center`** sehingga posisi teks otomatis tepat berada di tengah slide.
