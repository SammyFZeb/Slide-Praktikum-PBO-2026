# Instruksi Latihan

<div>
<ul>
<li>Lengkapi operasi data pada class <code>User</code> menggunakan JDBC.</li>
<li>Tambahkan method <code>updateEmail(Connection conn, String email)</code> menggunakan perintah <code>UPDATE</code>.</li>
<li>Tambahkan method <code>deleteUser(Connection conn)</code> menggunakan perintah <code>DELETE</code>.</li>
<li>Panggil kedua method tersebut pada class <code>Main</code>.</li>
<li>Kerjakan selama 20 menit.</li>
</ul>
</div>
