# Access Modifier

Access modifier membantu implementasi enkapsulasi dengan membatasi akses terhadap setiap bagian program yang berbeda.

<br>

|                   | class yang satu package | class beda package | 
| ----------------- | ----------------------- | ------------------ | 
| public            | ✅                      | ✅                | 
| private           | ❌                      | ❌                | 
| package (default) | ✅                      | ❌                 |
