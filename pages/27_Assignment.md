# Instruksi Tugas

<div>
<ul>
<li>Clone repo tugas dari Classmoji masing-masing.</li>
<li>Buka dokumen pada link berikut: </li>
<li>Baca soal dengan seksama. Setiap soal sudah ditambahkan unit test. Jalankan `mvn test` atau `mvn test -Dtest.groups=problem1`  (seperti yang ada di dokumen) untuk menguji kebenaran program.</li>
<li>Tugas diselesaikan hari ini sebagai sarana latihan.</li>
</ul>
</div>
