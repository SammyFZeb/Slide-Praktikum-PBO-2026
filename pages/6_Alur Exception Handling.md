# Exception Handling

<div class="grid grid-cols-2 gap-8 items-center mt-4">

<div class="text-sm leading-relaxed space-y-4">

<p>
Exception handling adalah <strong>mekanisme di mana sebuah alur khusus didefinisikan</strong> ketika sebuah kejadian berpotensi mengganggu alur kode program utama dan berpotensi menimbulkan crash.
</p>

<p>
Exception handling membuat <strong>jalur alternatif</strong> — menangani masalah lebih elegan daripada membiarkan program crash.
</p>
