# Lalu Apa "Kode Program Lain" Ini?

<div class="grid grid-cols-2 gap-8 mt-4 text-sm">

<div class="leading-relaxed space-y-4">

<p>
<strong>"Kode program lain"</strong> adalah sesuatu yang kita definisikan <em>secara sengaja</em> untuk dijalankan ketika terjadi exception.
</p>

<div class="border-l-2 border-red-500 pl-4 py-1">
<p class="font-semibold text-red-400">Jika tidak ada handler...</p>
<p>Jika terdapat exception tetapi tidak ada kode yang menanganinya → <strong>crash</strong> dan program berhenti.</p>
</div>

<div class="border-l-2 border-emerald-500 pl-4 py-1">
<p class="font-semibold text-emerald-400">Exception Handling</p>
<p>Ide pendefinisian kode program yang dijalankan ketika ada exception disebut sebagai <strong>exception handling</strong>.</p>
</div>

</div>

<div class="bg-gray-800 bg-opacity-60 rounded-xl p-5 border border-gray-600 flex flex-col justify-center text-sm">
<p class="text-center text-yellow-300 font-bold text-base mb-3">💡 Analogi Sederhana</p>
<p class="leading-relaxed">
Exception handling seperti <strong>prosedur darurat</strong> pada penerbangan.<br><br>
Alur normal = penerbangan mulus.<br>
Exception = mesin bermasalah.<br>
Exception Handling = prosedur darurat yang sudah disiapkan pilot — bukan membiarkan pesawat jatuh.
</p>
</div>

</div>
