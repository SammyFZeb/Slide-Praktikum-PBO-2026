# Lalu Apa "Kode Program Lain" Ini?

<div class="grid grid-cols-2 gap-8 mt-4 text-sm">

<div class="leading-relaxed space-y-4">

<p>
<strong>"Kode program lain"</strong> adalah sesuatu yang kita definisikan <em>secara sengaja</em> untuk dijalankan ketika terjadi exception.
</p>

<div v-click class="border-l-2 border-red-500 pl-4 py-1">
<p class="font-semibold text-red-400">Jika tidak ada handler...</p>
<p>Jika terdapat exception, tetapi tidak ada kode program yang bertugas menanganinya → <strong>crash</strong> dan program berhenti.</p>
</div>

<div v-click class="border-l-2 border-emerald-500 pl-4 py-1">
<p class="font-semibold text-emerald-400">Exception Handling</p>
<p>Ide pendefinisian kode program yang dijalankan ketika ada exception disebut sebagai <strong>exception handling</strong>.</p>
</div>

</div>

<div v-click class="bg-gray-800 bg-opacity-60 rounded-xl p-5 border border-gray-600 flex flex-col justify-center">
<p class="text-center text-yellow-300 font-bold text-base mb-3">💡 Analogi Sederhana</p>
<p class="text-center leading-relaxed">
Bayangkan program seperti pesawat terbang.<br><br>
<span class="text-blue-300">Alur normal</span> = penerbangan mulus dari A ke B.<br><br>
<span class="text-red-300">Exception</span> = mesin bermasalah.<br><br>
<span class="text-emerald-300">Exception Handling</span> = prosedur darurat yang sudah dilatih pilot — bukan membiarkan pesawat jatuh!
</p>
</div>

</div>
