# Kekurangan Encapsulation

<div>
<ul class="mt-10 space-y-6 text-left">
  <li >
    <span class="font-bold text-red-400 text-xl">Increased Code Complexity</span><br/>
    <span class="text-base">Menulis getter dan setter untuk setiap variabel membuat kode lebih panjang dan lebih kompleks.</span>
  </li>
  <li>
    <span class="font-bold text-purple-400 text-xl">Performance Overhead</span><br/>
    <span class="text-base">Mengakses data melalui metode memiliki <i>minor performance cost</i>.</span>
  </li>
  <li>
    <span class="font-bold text-green-400 text-xl">Less Flexibility</span><br/>
    <span class="text-base">Akses yang terlalu dibatasi dapat membatasi kemampuan class lain untuk menggunakan class tersebut secara efisien.</span>
  </li>
</ul>
</div>
