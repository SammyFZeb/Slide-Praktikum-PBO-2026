# Class Diagram

<div class="grid grid-cols-[40%_55%] gap-4 mt-8">

<div class="text-sm">

- Salah satu tipe UML yang sering digunakan adalah class diagram.
- Class diagram menunjukkan struktur dari suatu sistem, seperti kelas, method, atribut, dan hubungan di antaranya. 
- Class diagram membantu kita untuk memahami bagaimana sistem diatur dan bagaimana interaksi antar komponen terjadi.
